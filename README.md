# WorshipFlow Studio Web v0.4

Central profissional de apresentação e produção audiovisual para igrejas, eventos, escolas, empresas e auditórios.

## Recursos

- Prévia e programa lado a lado.
- Cenas com múltiplas fontes.
- Câmera e captura de tela.
- Vídeos, músicas, imagens e apresentações em PDF.
- Vídeos do YouTube por link.
- Letras de louvores e textos.
- Controle independente de áudio.
- Transições, blackout e janela exclusiva para telão.
- Programação de eventos e gravação local.

## Versão publicada

Os arquivos `index.html`, `worshipflow.css` e `worshipflow.js` formam a versão web pronta para o GitHub Pages.

O arquivo `WorshipFlow-Studio-Web-v0.4.zip` contém o projeto completo em React, TypeScript, Vite e Electron.

## Execução local

Extraia o projeto completo e execute `INICIAR-WEB.bat` no Windows.
